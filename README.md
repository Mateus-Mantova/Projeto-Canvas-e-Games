# 🚀 Space Escape

Jogo desenvolvido com p5.js onde o jogador controla uma nave espacial e deve desviar de meteoros.

## Como jogar
- Use as setas do teclado
- Desvie dos meteoros
- Sobreviva o máximo possível

## Mecânicas
- Sistema de vidas
- Dificuldade progressiva
- Pontuação baseada no tempo
- Recorde salvo no navegador

## Tecnologias
- JavaScript
- p5.js
